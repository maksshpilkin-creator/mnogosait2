## Независимая проверка исходников

| Критерий | Результат |
|---|---|
| Ограниченный набор эффектов | Однократные эффекты имеют длительность 200–620 мс; reveal использует задержки до 240 мс. Единственный постоянный цикл — надпись круговой CTA, 38 секунд. Имплант и лента направлений не получили бесконечного движения. |
| Отмена drawer | `moveDrawer` читает текущие transform/opacity до отмены старого эффекта. Новый объект состояния в WeakMap делает прежние завершения неактуальными. |
| Закрытие и блокировка | `is-leaving` сохраняет отрисовку на время выхода; `syncScrollLock` учитывает открытые и закрывающиеся панели обоих типов. Закрывающаяся панель сразу получает inert/aria-hidden в вызывающем модуле. |
| Фокус | При открытии вызывается прежнее удержание фокуса; при закрытии оно снимается. Escape возвращает фокус, а переход из drawer к форме дожидается актуального завершения выхода. |
| FAQ | Текущая высота снимается перед отменой; token состояния не даёт старому callback скрыть повторно открытый ответ. Закрывающийся ответ inert; итоговый hidden задаётся после актуального завершения. |
| Отмена без rejection | `effect.done` разрешается по событиям finish/cancel. Код не создаёт неотловленную цепочку `animation.finished`, отклоняемую при отмене. |
| Reduced motion и пауза | `updatePreference` отслеживает matchMedia change, меняет режим документа и завершает текущие WAAPI-эффекты. CSS media query отключает циклы и transitions; app-пауза останавливает круг и возвращает scroll-behavior к auto. |
| Hover/focus на круге | CSS явно ставит animation-play-state: paused при hover/focus-within. При снятии фокуса в полном режиме цикл может продолжиться. |
| Fail-open | Базовые стили оставляют секции видимыми. Без IntersectionObserver не запускаются reveal секций; без поддержки animate выбирается reduced-режим. Фокус внутри reveal отменяет его и снимает наблюдение. |
| Данные и демо | Motion работает с визуальными состояниями, не отправляет заявки и не переписывает цены/форму. Noindex, маркировка условных данных и явное «не отправлено» сохранены. Новых npm-зависимостей нет. |

## Независимые проверки логики в памяти

Выполнены три узких Node/VM сценария без файлов, сети и управления браузером.
Использован настоящий `motion.js`, подменены matchMedia, минимальный DOM и
FakeAnimation с событиями finish/cancel. Все три завершились с кодом 0:

1. **Смена reduced-motion во время drawer.exit:** `is-leaving` обеих частей
   очищен, открытое состояние снято, body lock выключен, режим — reduced.
2. **Смена reduced-motion во время FAQ.enter:** ответ остаётся видимым,
   `hidden=false`, `inert=false`, `is-animating` удалён.
3. **Быстрое open → close → reopen:** результаты операций `[false, false, true]`;
   итоговая панель открыта, backdrop открыт, body lock сохранён. Устаревшие
   callbacks не скрыли актуальную панель.

Это проверка логики завершения. Она не является эмуляцией настройки ОС,
проверкой настоящего layout/WAAPI или заменой живого браузера.

## Браузерные наблюдения root

Ниже — действия главного агента через CUA, а не собственные действия проверяющего.
Матрица и итог сохранены в `reports/motion-browser-checks.json`, файл прочитан:

- Hero наблюдался сначала с opacity 0 / translateY(16px), затем с opacity 1 /
  transform none. Превью HG-02 начинает переход с .35 / translateY(4px).
- Меню: translateX(-420px) → none; быстрые open → Escape → Enter до конца
  выхода оставляют его открытым и доступным, body lock сохраняется.
- Price drawer: translateX(620px) → открытое состояние; тот же быстрый сценарий
  не оставляет устаревшего закрытого состояния. CTA дожидается выхода, выбирает
  услугу в форме и снимает body lock.
- FAQ: ответ проходит высоту 0 → итоговую высоту; два быстрых переключения
  возвращают согласованное состояние, `is-animating` снимается. На 375 px
  ответ №3 завершился на 157 px, aria-expanded=true.
- App-пауза: data-motion=paused, круг paused, прокрутка auto; меню работает
  без движения. Возобновление даёт full/running. Фокус на круговой CTA ставит
  цикл на паузу; уход Tab позволяет продолжение.
- На мобильном drawer «ПРОТЕЗИРОВАНИЕ» помещается в ширину, заголовок остаётся
  в одну строку; Escape закрывает панель и освобождает body.
- Локальный черновик формы по-прежнему явно сообщает отсутствие отправки,
  содержит выбранные значения и не очищает имя.
- В журнале root не обнаружены error/warn. Сломанных img — 0.

## Границы и итог

- Подтверждённых P0/P1/P2 в назначенной области не найдено.
- Реальный системный prefers-reduced-motion и изменение настройки ОС
  **не проверялись в браузере**: CUA не предоставлял emulation capability.
  Эта ветка проверена исходниками и описанными VM-сценариями. Живая app-пауза
  не выдаётся за тест OS reduced-motion.
- Puppeteer-suite не запускался этим проверяющим. В `test-interactive.js`
  предусмотрены ожидание окончания выхода и emulateMediaFeatures для reduced;
  наличие этого кода не приравнивается к выполненному тесту.
- Отсутствие JS/IntersectionObserver/WAAPI проверено по fail-open архитектуре,
  без отдельного живого браузера с отключёнными API.
- Не проводились публикация, реальная отправка заявки, смена настроек ОС,
  широкая кроссбраузерная проверка или проверка медицинских данных клиники.

Приёмка относится к локальному демо и выбранной сдержанной подаче движения.
