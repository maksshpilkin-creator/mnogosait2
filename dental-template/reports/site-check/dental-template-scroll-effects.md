# Сводка независимой проверки scroll-effects

Дата: 22.11.2026. Этот файл записан root по сообщениям отдельного business_verifier. Он не является подписанным проверяющим итоговым отчётом.

Независимо проверены HTML/CSS/JS нового набора эффектов. Проверяющий подтвердил статическую семантику всех21 price-row ссылок: распределение4/3/3/4/4/3, корректные категории, понятные aria-label, href#booking, доступность черезfocus и на touch. Hero-декор и marquee исключены из AX; стрелка отделена от вращающегося текста, половины ticker симметричны.

Проверяющий обнаружил и вернул разработчику:

1. Контраст4.478 в середине тёмной темы — исправлен выбором pure black/white.
2. Fade кнопки превью после keyboard focus — исправлен focusin cleanup и пропуском fade для сфокусированной панели.
3. Queued frame скрытой вкладки — добавлены hidden/visibilitychange guards.
4. Поздний fonts.ready после destroy — добавлен destroyed guard.

Сообщены успешные независимые in-memory VM/математические сценарии на реальных модулях:

- 20 scroll событий дают один RAF, render не создаёт вечную петлю. Pause/reduced отменяют queued frame, hero shifts0/fill1/theme1; resume использует текущую геометрию.
- Hidden отменяет frame и блокирует scroll/resize/refresh; visible обновляет один раз. Destroy снимает listeners и блокирует отложенный fonts.ready.
- Расчёт10 001 положения темы после исправления: minimum foreground/secondary contrast4.6075. Accent минимум3.1269 относится к крупным цифрам/заголовку.
- HG→SG→PR сохраняют PR. Четыре исходящих слоя inert/aria-hidden, без ID/контролов, удалены после exit, пока incoming ещё идёт.
- Focusin сразу завершает переход; уже сфокусированная кнопка не затухает при обновлении. Runtime reduced очищает слои и сохраняет контент.
- Actual exclusive FAQ1→2→1 и reduced во время открытия оставляют один ответ с согласованными aria-expanded/hidden/inert.

Это независимая проверка кода/логики с управляемыми зависимостями и математики, не эмуляция браузерного рендера или настройки ОС. Root отдельно провёл живой UI проход и сохранил [JSON](../scroll-effects-browser-checks.json) и кадры screenshots/scroll-effects/.
