# Сводка независимой проверки анимаций «ЭМАЛЬ»

Дата: 22.11.2026. Файл записан главным агентом по сообщениям отдельного business_verifier. Это не подписанный проверяющим итоговый отчёт.

Проверяющий изучил motion.js/css, services.js, источники и геометрическую базу. Он обнаружил возврат opacity closing backdrop в промежутке 240–280 мс. Разработчик исправил его удержанием прозрачного финала.

Проверяющий сообщил о четырёх успешных in-memory Node/VM сценариях с настоящим motion.js:

1. Быстрые HG → SG → PR сохраняют последнюю услугу. Клоны inert/aria-hidden, без ID, после завершения удалены.
2. Ручная пауза сразу удаляет слои. Старые завершения не удаляют новый переход после resume.
3. Reduced-motion и focus завершают reveal текста с восстановлением исходного HTML и BR.
4. Отказ animate при отсутствующем IntersectionObserver оставляет текст доступным и не оставляет маски.

Это проверка логики с управляемыми зависимостями, не эмуляция рендера браузера/ОС. Отмечен неблокирующий P3: выделение текста во время reveal может сброситься при очистке временных узлов.

Отдельная финальная визуальная приёмка агентом не завершена: выполнение остановилось по лимиту использования до записи итогового отчёта. Независимый общий final pass не заявляется.
