## 📁 Структура каталогов

| Каталог / Файл | Назначение | Важность для ИИ |
| :--- | :--- | :---: |
| **`sales/`** | **Центр продаж и переписки.** Содержит `CALL_STATION.html` (воркстейшн на 119 салонов), скрипты переписки (`FULL_SALES_STACK.md`, `OUTREACH_PLAYBOOK.md`), базу контактов `owners_telegram.json`. | 🔴 Высокая |
| **`data/facts/`** | **119 карточек фактов бизнесов** (`<slug>.json`). Ground Truth: адреса, подтверждённые телефоны, статусы проверки карт, каталоги техники. | 🔴 Высокая |
| **`dental-template/`** | **Автономный Vite-проект современных лендингов.** Здесь живёт `triamoto.html` (мотосалон Триамото, Дзержинск) и `index.html` (стоматология ЭМАЛЬ). Деплоится на Vercel. | 🔴 Высокая |
| **`scripts/`** | Скрипты сборки и верификации: `build-call-station.js`, `verify-sales-stack-sync.js`, `find-owners.js`, `build-reference.js`. | 🔴 Высокая |
| **`template/`** | Исходный статический шаблон эталона мотосалона (`motodrive54`). | 🟡 Средняя |
| **`dist/`** | Скомпилированные артефакты: `dist/station/` (публичная станция), `dist/motodrive54/` (эталонный салон), 119 сгенерированных страниц. | 🟡 Средняя |
| **`reports/`** | Независимые отчёты фактчекинга, проверки верстки и аудита сайтов. | 🟢 Справочно |
| **`полезное/`** | База знаний: правила переписки, рекомендации коуча, шаблоны ответов на возражения лидов, инструкции по Miro. | 🟢 Справочно |
| **`tools/parser-2gis/`** | Локальный Python-парсер карточек организаций 2ГИС. | 🟢 Инструмент |
| **`checkpoints/`** | Контрольные точки и архивные манифесты разработки эталона. | ⚪ Архив |

## ⛔ Обязательные правила для ИИ (Ground Truth Invariants)

1. **Никогда не выдумывать факты бизнеса.**  
   Цены, телефоны, отзывы, часы работы, наличие моделей берутся **только** из подтверждённых карточек `data/facts/` или открытых источников (Яндекс Карты, 2ГИС). Правдоподобная цена может быть галлюцинацией.
2. **Не запускать устаревшие команды:**  
   `npm run all`, `npm run generate`, `npm run dossiers` **заблокированы/запрещены** — они работают по старой логике и могут перезаписать проверенные данные.
3. **Все три копии станции должны быть идентичны:**  
   `sales/CALL_STATION.html`, `dist/station/index.html` и `dist/station.html` всегда собираются вместе скриптом `npm run build:station` и проверяются тестом `npm run verify:station`.
4. **Формат обращения:**  
   Обращаться к пользователю — **Максим**. Тон: практичный, энергичный, без корпоративного пафоса и «воды».

## ⚡ Шпаргалка команд

### Станция звонков и переписки (Трек 1)
```bash
# Пересобрать станцию CALL_STATION.html (синхронно во всех 3 путях):
npm run build:station

# Запустить строгую проверку целостности и отсутствия расхождений:
npm run verify:station

# Запустить пересборку и тест в один шаг:
npm run test:station
```

### Современные лендинги на Vite (Трек 2)
```bash
# Сборка продакшн-бандла (index.html + triamoto.html):
npm run build:triamoto

# Полный E2E-тест верстки, интерактивности и доступности Триамото:
npm run test:triamoto

# Дизайн-аудит (WCAG 2.5.5, тач-таргеты >= 44px, контрастность):
npm run audit:triamoto

# Локальный предпросмотр Vite (порт 4173):
cd dental-template && npm run preview
```

### Сборка эталонного сайта мотосалона
```bash
npm run build:reference
```
